# Fiona Wawira Njeru — Portfolio Website

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Edit `index.html` for text, `style.css` for appearance, and `script.js` for interactions.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `fiona-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL.

## Presentation
The PowerPoint file is provided separately. Upload it to Google Drive, right-click it, choose **Open with → Google Slides**, then use **File → Save as Google Slides** if you want a native Slides copy.
